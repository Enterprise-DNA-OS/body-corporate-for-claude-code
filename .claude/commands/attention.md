1. Run `npm run strata -- attention [--manager=]`.
2. Present it in the order the output already uses: money risk first (arrears, expired insurance), then statutory deadlines (AGMs, disclosure clocks, meeting notice), then the building (habitability work, committee bottlenecks), then hygiene (minutes, invoices, tasks, quiet schemes).
3. For each group, one line per item: the scheme, the person or record, how many days, and what doing something about it looks like.
4. Anything with EXPIRED or OVERDUE in it goes in the first three lines of your answer no matter what group it is in. An expired principal policy is an uninsured building.
5. End with the five things to do today, picked by risk first and money second, each with the exact command that records the action once it is done.

This list is built from the same views the compliance check uses. If the operator disputes an item, open the underlying record (`scheme`, `lot`, `maintenance <ref>`) rather than re-arguing the list.

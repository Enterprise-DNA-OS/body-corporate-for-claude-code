description: One lot's whole file. The owner, the utility interest, every levy charged and every payment received, the arrears ladder, disclosures and the contact log.
---

1. Run `npm run strata -- lot <ref, unit label or owner name>`.
2. Answer the question first if there was one ("does 7 owe us money", "who owns the penthouse"), then the card.
3. If the lot is in arrears, always state the ladder position: what has been sent, what has not, and the next rung.
4. The levy ledger on this card is a record so the arrears maths works. Never present it as a bank statement.

An ambiguous name lists the candidates and stops. Pick with the operator; never guess an owner's file.
